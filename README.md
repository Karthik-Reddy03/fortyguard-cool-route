# 🌡️ FortyGuard Cool-Route Navigator

An intelligent microclimate navigation engine built for the **FortyGuard Hackathon '26**.

## 📌 Project Overview
Standard weather tools provide high-altitude macro-level temperatures that miss hyper-local street heat. The **Cool-Route Navigator** leverages FortyGuard’s 2-meter ground-level temperature data to calculate heat exposure along urban paths—guiding pedestrians, outdoor workers, and logistics teams away from dangerous asphalt heat traps.

## 🚀 Key Features
* **The 2-Meter Gap Analysis:** Visualizes real ground temperatures vs. standard ambient air forecasts.
* **Cool Route vs. Fast Route:** Compares direct exposure routes against shaded, cooler alternative paths.
* **12-Hour Heat Forecasting:** Uses FortyGuard's predictive models to plan safe travel windows.

## 🛠️ Tech Stack & API Usage
* **Frontend:** React / Mapbox GL JS
* **Backend:** Node.js / Python
* **API Integration:** FortyGuard Temperature API® (`/v1/heatmap`, `/v1/status`)
